# Reports

Generated by each test run (`npm test`, then `npm run summary`):

- `html/index.html` – Playwright HTML report (open with `npm run report`)
- `junit.xml` – JUnit results
- `results.json` – raw Playwright JSON
- `SUMMARY.md` – readable summary: counts per project, known defects exercised, Web Vitals and other measurements

CI also uploads these as a build artifact and publishes the HTML report to GitHub Pages.
